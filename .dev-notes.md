## Database migrations (Alembic)

Alembic is now set up at `backend/alembic/`. Use it for all schema changes going forward.

**New database setup (fresh Supabase project):**
```bash
cd backend
alembic upgrade head          # creates all tables
```

**Existing database (already set up with init_db):**
```bash
cd backend
alembic stamp head            # tells Alembic current DB is at 0001 without running migrations
```

**Add a new migration after changing models.py:**
```bash
cd backend
alembic revision --autogenerate -m "describe change"
alembic upgrade head
```

**Never change existing migration files** — always add new ones.
